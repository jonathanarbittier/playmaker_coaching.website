# Playmaker Football Coaching

Premium, mobile-first demo website built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Hero media

The approved training reel is served in separate optimized desktop and phone variants from `public/videos/`. It is configured for muted autoplay, looping, inline playback, cover cropping and reduced-motion fallback.
